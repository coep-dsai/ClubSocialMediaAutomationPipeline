# Agentic Social Media Automator

An open-source Agentic AI pipeline built by the COAP Data Science and AI Club to automate the creation of social media posts, blogs, and newsletters.

## 🎯 Goal
To create a fully automated, zero-cost pipeline that generates high-quality, formatted content. Our first initiative is the **"This Week in AI"** pipeline, which runs weekly to:
1. Scrape the web for the latest AI news and research.
2. Filter and compress the findings into bite-sized summaries.
3. Overlay the text onto static club design templates.
4. Export ready-to-post Instagram carousels.

## 📂 Project Structure
* `agents/`: Core AI agent definitions (e.g., Researcher, Editor, Designer).
* `pipelines/`: End-to-end workflows connecting the agents.
* `templates/`: Static image backdrops, fonts, and design assets.
* `notebooks/`: Jupyter notebooks for sandbox testing and prompt prototyping.

## 🤝 Vision
Built for the community. We are designing this architecture so other university clubs can easily fork the repo, plug in their own branding, and automate their outreach.
